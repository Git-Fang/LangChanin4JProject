# 联网搜索实现文档

## 1. 概述

本文档描述了项目中联网搜索功能的完整实现过程。该功能基于 **DuckDuckGo Instant Answer API** 实现，为 AI 助手提供实时网络搜索能力。

### 1.1 功能特性

| 特性 | 说明 |
|------|------|
| 搜索 API | DuckDuckGo Instant Answer API (免费，无需 API Key) |
| 返回结果 | 即时答案 (Instant Answer) + 相关链接 |
| 最大结果数 | 8 条搜索结果 |
| 超时配置 | 连接超时 30s，读取超时 600s |
| 响应格式 | JSON |

## 3. 核心代码实现

### 3.1 WebSearchTools 实现

**文件位置**: `src/main/java/org/fb/tools/WebSearchTools.java`

```java
@Component
public class WebSearchTools {
    private static final String DDG_API_URL = "https://api.duckduckgo.com/";
    
    @Autowired
    private WebClient.Builder webClientBuilder;
    
    private final ObjectMapper objectMapper = new ObjectMapper();

    @Tool(name = "web_search", value = "网络搜索工具:当需要查询最新信息、实时数据或知识库以外的内容时使用此工具进行网络搜索。根据{{searchQuery}}搜索互联网并返回相关结果")
    public String webSearch(@P(value = "searchQuery", required = true) String searchQuery) {
        // 1. 构建 API 请求 URL
        String apiUrl = DDG_API_URL + "?q=" + java.net.URLEncoder.encode(searchQuery, "UTF-8") 
                + "&format=json&no_html=1&skip_disambig=1&ia=web";
        
        // 2. 发起 HTTP GET 请求
        String response = webClientBuilder.build()
                .get()
                .uri(apiUrl)
                .header("User-Agent", "Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36")
                .retrieve()
                .bodyToMono(String.class)
                .block();

        // 3. 解析 JSON 响应
        return parseSearchResults(response, searchQuery);
    }
}
```

### 3.2 搜索结果解析逻辑

```java
private String parseSearchResults(String jsonResponse, String searchQuery) {
    JsonNode rootNode = objectMapper.readTree(jsonResponse);
    
    // 优先级1: 即时答案 (Instant Answer)
    JsonNode abstractNode = rootNode.path("AbstractText");
    if (!abstractNode.isMissingNode() && !abstractNode.asText().isEmpty()) {
        // 返回即时答案 + 来源 + 相关链接
    }
    
    // 优先级2: 相关主题 (Related Topics)
    JsonNode relatedTopics = rootNode.path("RelatedTopics");
    if (!relatedTopics.isMissingNode() && relatedTopics.isArray()) {
        // 返回最多8条搜索结果
    }
    
    // 优先级3: 无结果返回
    return "未找到与 '" + searchQuery + "' 相关的网络结果。";
}
```

### 3.3 HTTP 客户端配置

**文件位置**: `src/main/java/org/fb/config/WebClientConfig.java`

```java
@Configuration
public class WebClientConfig {
    private static final int CONNECT_TIMEOUT = 30;           // 连接超时 30s
    private static final int READ_TIMEOUT = 600;             // 读取超时 600s
    private static final int MAX_IN_MEMORY_SIZE = 10 * 1024 * 1024;  // 10MB
    private static final int MAX_CONNECTIONS = 100;          // 最大连接数
    private static final int MAX_IDLE_CONNECTIONS = 20;      // 最大空闲连接
    
    @Bean
    public WebClient webClient() {
        // 1. 配置连接池
        ConnectionProvider connectionProvider = ConnectionProvider.builder("ai-chat-pool")
                .maxConnections(MAX_CONNECTIONS)
                .maxIdleTime(Duration.ofSeconds(30))
                .pendingAcquireTimeout(Duration.ofSeconds(60))
                .build();
        
        // 2. 配置 HTTP 客户端
        HttpClient httpClient = HttpClient.create(connectionProvider)
                .option(ChannelOption.CONNECT_TIMEOUT_MILLIS, CONNECT_TIMEOUT * 1000)
                .responseTimeout(Duration.ofSeconds(READ_TIMEOUT));
        
        // 3. 配置编解码器
        ExchangeStrategies strategies = ExchangeStrategies.builder()
                .codecs(configurer -> configurer
                        .defaultCodecs()
                        .maxInMemorySize(MAX_IN_MEMORY_SIZE))
                .build();
        
        return WebClient.builder()
                .clientConnector(new ReactorClientHttpConnector(httpClient))
                .exchangeStrategies(strategies)
                .build();
    }
}
```

## 5. API 调用流程

### 5.1 DuckDuckGo API 请求格式

```
GET https://api.duckduckgo.com/
  ?q={searchQuery}              // 搜索关键词 (URL 编码)
  &format=json                  // 返回 JSON 格式
  &no_html=1                    // 不包含 HTML 标签
  &skip_disambig=1              // 跳过消歧义页面
  &ia=web                       // 执行网页搜索
```

### 5.2 API 响应结构

```json
{
  "AbstractText": "即时答案内容摘要...",
  "AbstractSource": "Wikipedia",
  "AbstractURL": "https://en.wikipedia.org/wiki/...",
  "RelatedTopics": [
    {
      "Text": "相关结果标题",
      "URL": "https://example.com/article"
    }
  ],
  "Image": "https://..."
}
```

### 5.3 响应处理策略

| 优先级 | 字段 | 处理方式 |
|--------|------|----------|
| 1 | `AbstractText` | 即时答案优先返回 |
| 2 | `RelatedTopics` | 最多返回 5 条相关链接 |
| 3 | 无结果 | 返回友好提示 |

## 8. 使用场景

根据系统提示词，搜索工具在以下场景使用：

1. **查询最新信息**：AI 知识库不包含的实时数据
2. **查询知识库以外的内容**：本地知识库未覆盖的领域
3. **验证实时数据**：需要确认的最新统计或新闻
4. **补充知识库**：当本地知识库和向量数据库都无结果时的兜底方案

### 8.1 调用优先级

```
本地知识库 (knowledge/) 
    ↓ 无结果
向量数据库检索 (Qdrant) 
    ↓ 无结果
结构化数据查询 (MySQL/MongoDB)
    ↓ 无结果
网络搜索 (WebSearchTools) ← 兜底方案
    ↓ 无结果
通用大模型知识回答
```

## 9. 注意事项

1. **免费 API 限制**：DuckDuckGo API 为免费服务，有频率限制，生产环境建议考虑付费方案
2. **User-Agent**：必须设置有效的 User-Agent，否则可能被拒绝访问
3. **URL 编码**：搜索关键词必须进行 URL 编码处理
4. **结果截断**：即时答案过长时建议截断展示
5. **错误处理**：需要做好网络异常捕获和用户友好提示
