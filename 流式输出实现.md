## 1. 概述

项目实现了三种流式输出方案：

| 模式 | 前端页面 | 协议 | 适用场景 |
|------|---------|------|---------|
| HTTP流式输出 | unified.html (HTTP模式) | POST + SSE | 简单的一问一答场景 |
| SSE实时聊天 | chat-sse.html | Kafka + SSE | 高并发、需要消息队列解耦的场景 |
| MCP SSE模式 | unified.html (SSE模式) | JSON-RPC 2.0 + SSE | 需要调用外部工具的场景 |

### 1.1 技术栈

- **后端**: Spring Boot + WebFlux (响应式编程)
- **消息队列**: Apache Kafka
- **缓存**: Redis
- **前端**: 原生JavaScript + EventSource API
- **流式协议**: Server-Sent Events (SSE)

### 1.2 核心流程

```
用户输入 → 前端发送请求 → 后端处理 → SSE推送 → 前端渲染
```

## 2. HTTP流式输出模式

HTTP流式输出模式是一种简单直接的流式实现方案，适用于简单的一问一答场景。

### 2.1 接口定义

#### 2.1.1 发起请求

**接口**: `POST /xiaozhi/chat/http-stream`

**请求参数**:
```json
{
  "memoryId": 1702876800000,
  "message": "你好，请介绍一下自己"
}
```

**响应**:
```json
{
  "requestId": "http_1702876800000_1",
  "streamUrl": "/xiaozhi/chat/http-stream/http_1702876800000_1"
}
```

#### 2.1.2 流式获取结果

**接口**: `GET /xiaozhi/chat/http-stream/{requestId}`

**Content-Type**: `text/event-stream`

### 2.2 后端实现

#### 2.2.1 控制器代码

位置: `AsyncChatController.java`

```java
@PostMapping("/chat/http-stream")
@Operation(summary = "HTTP流式聊天", description = "通过POST发送消息，SSE流式返回结果")
public Map<String, Object> startHttpStreamChat(@RequestBody ChatForm chatForm) {
    Long memoryId = chatForm.getMemoryId();
    String userMessage = chatForm.getMessage();
    
    log.info("收到HTTP流式聊天请求, memoryId: {}, message: {}", memoryId, userMessage);
    
    // 生成唯一请求ID
    String requestId = "http_" + System.currentTimeMillis() + "_" + Thread.currentThread().getId();
    
    // 将请求信息存入Redis
    try {
        String requestJson = objectMapper.writeValueAsString(
            ChatRequestMessage.create(memoryId, userMessage)
        );
        redisTemplate.opsForValue().set("chat:request:" + requestId, requestJson, RESULT_TTL);
        redisTemplate.opsForValue().set(STREAM_CACHE_PREFIX + requestId, "", RESULT_TTL);
    } catch (Exception e) {
        log.error("保存请求数据失败, requestId: {}", requestId, e);
    }
    
    // 返回流式URL
    Map<String, Object> response = new HashMap<>();
    response.put("requestId", requestId);
    response.put("streamUrl", "/xiaozhi/chat/http-stream/" + requestId);
    
    return response;
}
```

#### 2.2.2 SSE流处理

```java
@GetMapping(value = "/chat/http-stream/{requestId}", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter streamHttpChat(@PathVariable String requestId) {
    log.info("HTTP流式聊天SSE连接, requestId: {}", requestId);
    
    // 创建SSE发射器，设置超时时间为5分钟
    SseEmitter emitter = new SseEmitter(SSE_TIMEOUT);
    sseConnections.put(requestId, emitter);
    
    try {
        // 1. 发送连接成功事件
        sendSseEvent(emitter, "connected", Map.of(
            "status", "connected",
            "requestId", requestId,
            "timestamp", System.currentTimeMillis(),
            "mode", "http-stream"
        ));
        
        // 2. 从Redis获取请求信息
        String requestJson = redisTemplate.opsForValue().get("chat:request:" + requestId);
        ChatRequestMessage request = objectMapper.readValue(requestJson, ChatRequestMessage.class);
        
        // 3. 使用流式服务处理
        if (streamingChatService != null) {
            redisTemplate.opsForValue().set(STREAM_CACHE_PREFIX + requestId, "", RESULT_TTL);
            
            Flux<String> flux = streamingChatService.chat(memoryId, message);
            
            AtomicReference<String> accumulated = new AtomicReference<>("");
            AtomicReference<Long> startTime = new AtomicReference<>(System.currentTimeMillis());
            
            // 订阅流式内容
            flux.publishOn(Schedulers.boundedElastic())
                .doOnNext(chunk -> {
                    // 累计内容
                    String current = accumulated.get();
                    String updated = current + chunk;
                    accumulated.set(updated);
                    
                    // 更新Redis缓存
                    redisTemplate.opsForValue().set(
                        STREAM_CACHE_PREFIX + requestId, 
                        updated, 
                        RESULT_TTL
                    );
                    
                    // 发送内容块事件
                    sendSseEvent(emitter, "chunk", Map.of(
                        "content", chunk,
                        "status", "streaming",
                        "fullContent", updated,
                        "progress", 50
                    ));
                })
                .doOnComplete(() -> {
                    // 处理完成
                    long processingTime = System.currentTimeMillis() - startTime.get();
                    String finalContent = accumulated.get();
                    
                    ChatResultMessage finalResult = ChatResultMessage.builder()
                        .requestId(requestId)
                        .memoryId(memoryId)
                        .result(finalContent)
                        .status(ChatResultMessage.ResultStatus.SUCCESS)
                        .processingTimeMs(processingTime)
                        .build();
                    
                    // 缓存最终结果
                    String jsonResult = objectMapper.writeValueAsString(finalResult);
                    redisTemplate.opsForValue().set(RESULT_CACHE_PREFIX + requestId, jsonResult, RESULT_TTL);
                    
                    // 发送完成事件
                    sendSseEvent(emitter, "result", Map.of(
                        "requestId", requestId,
                        "memoryId", memoryId,
                        "status", "SUCCESS",
                        "result", finalContent,
                        "processingTimeMs", processingTime
                    ));
                    sendSseEvent(emitter, "complete", Map.of("event", "complete"));
                    emitter.complete();
                    sseConnections.remove(requestId);
                })
                .doOnError(error -> {
                    // 处理错误
                    log.error("HTTP流式处理错误, requestId: {}", requestId, error);
                    sendSseEvent(emitter, "error", Map.of(
                        "status", "error",
                        "message", error.getMessage()
                    ));
                    emitter.completeWithError(error);
                    sseConnections.remove(requestId);
                })
                .subscribe();
        }
        
    } catch (Exception e) {
        log.error("HTTP流式初始化异常, requestId: {}", requestId, e);
        emitter.completeWithError(e);
        sseConnections.remove(requestId);
    }
    
    // 设置超时回调
    emitter.onTimeout(() -> {
        log.warn("HTTP流式超时, requestId: {}", requestId);
        emitter.complete();
        sseConnections.remove(requestId);
    });
    
    return emitter;
}
```

## 3. SSE实时聊天模式

SSE实时聊天模式基于Kafka消息队列实现，适用于高并发场景，可以实现请求与处理的解耦。

### 3.1 接口定义

#### 3.1.1 异步提交请求

**接口**: `POST /xiaozhi/chat/async`

**请求参数**:
```json
{
  "memoryId": 1702876800000,
  "message": "请翻译以下文章..."
}
```

**响应**:
```json
{
  "requestId": "uuid-xxxx-xxxx",
  "status": "PROCESSING",
  "message": "请求已提交",
  "resultUrl": "/xiaozhi/result/uuid-xxxx-xxxx",
  "streamUrl": "/xiaozhi/chat/stream/uuid-xxxx-xxxx"
}
```

#### 3.1.2 流式获取结果

**接口**: `GET /xiaozhi/chat/streaming/{requestId}`

**Content-Type**: `text/event-stream`

### 3.2 后端实现

#### 3.2.1 异步请求处理

```java
@PostMapping("/chat/async")
public Map<String, Object> asyncChat(@RequestBody ChatForm chatForm) {
    Long memoryId = chatForm.getMemoryId();
    String userMessage = chatForm.getMessage();
    
    log.info("收到异步聊天请求, memoryId: {}, message: {}", memoryId, userMessage);
    
    // 创建请求消息
    ChatRequestMessage request = ChatRequestMessage.create(memoryId, userMessage);
    
    // 将请求存入Redis
    try {
        String requestJson = objectMapper.writeValueAsString(request);
        redisTemplate.opsForValue().set("chat:request:" + request.getRequestId(), requestJson, RESULT_TTL);
    } catch (Exception e) {
        log.error("保存请求数据失败, requestId: {}", request.getRequestId(), e);
    }
    
    // 发送到Kafka
    if (isStandalone()) {
        processSynchronously(request);
    } else {
        requestProducer.sendRequest(request);
    }
    
    // 返回请求ID和流式URL
    Map<String, Object> response = new HashMap<>();
    response.put("requestId", request.getRequestId());
    response.put("status", "PROCESSING");
    response.put("message", "请求已提交");
    response.put("streamUrl", "/xiaozhi/chat/stream/" + request.getRequestId());
    
    return response;
}
```

#### 3.2.2 Kafka消费者处理

位置: `ChatRequestConsumer.java`

```java
@KafkaListener(
    topics = "ai-chat-request",
    groupId = "ai-request-consumer",
    containerFactory = "chatRequestListenerContainerFactory"
)
public void consumeChatRequest(ConsumerRecord<String, ChatRequestMessage> record, Acknowledgment ack) {
    ChatRequestMessage request = record.value();
    log.info("收到AI请求, requestId: {}", request.getRequestId());
    
    try {
        // 1. 清空流式内容缓存
        clearStreamContent(request.getRequestId());
        
        // 2. 发送处理中状态
        ChatResultMessage processingResult = ChatResultMessage.builder()
            .requestId(request.getRequestId())
            .memoryId(request.getMemoryId())
            .status(ChatResultMessage.ResultStatus.PROCESSING)
            .build();
        cacheResult(request.getRequestId(), processingResult);
        
        long startTime = System.currentTimeMillis();
        
        // 3. 异步处理请求
        CompletableFuture.supplyAsync(() -> processRequest(request), mdcExecutorService)
            .thenAccept(result -> {
                long processingTime = System.currentTimeMillis() - startTime;
                result.setProcessingTimeMs(processingTime);
                
                // 4. 缓存结果和流式内容
                cacheResult(request.getRequestId(), result);
                updateStreamContent(request.getRequestId(), result.getResult());
                
                // 5. 发送结果到结果队列
                requestProducer.sendResult(result);
                
                log.info("请求处理完成, requestId: {}, 处理时间: {}ms", 
                    request.getRequestId(), processingTime);
                ack.acknowledge();
            })
            .exceptionally(ex -> {
                // 处理异常
                log.error("请求处理异常, requestId: {}", request.getRequestId(), ex);
                ChatResultMessage failedResult = ChatResultMessage.builder()
                    .requestId(request.getRequestId())
                    .memoryId(request.getMemoryId())
                    .status(ChatResultMessage.ResultStatus.FAILED)
                    .errorMessage(ex.getMessage())
                    .build();
                cacheResult(request.getRequestId(), failedResult);
                ack.acknowledge();
                return null;
            });
            
    } catch (Exception e) {
        log.error("消费消息异常, requestId: {}", request.getRequestId(), e);
        ack.acknowledge();
    }
}
```

#### 3.2.3 SSE流推送

```java
@GetMapping(value = "/chat/stream/{requestId}", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
public SseEmitter streamResult(@PathVariable String requestId) {
    log.info("建立SSE连接, requestId: {}", requestId);
    
    SseEmitter emitter = new SseEmitter(SSE_TIMEOUT);
    String cacheKey = RESULT_CACHE_PREFIX + requestId;
    sseConnections.put(requestId, emitter);
    
    try {
        // 1. 发送连接成功事件
        sendSseEvent(emitter, "connected", Map.of(
            "status", "connected",
            "requestId", requestId,
            "timestamp", System.currentTimeMillis()
        ));
        
        // 2. 轮询检查结果
        long startTime = System.currentTimeMillis();
        long timeout = SSE_TIMEOUT - 5000;
        long checkInterval = 100;
        int lastContentLength = 0;
        
        while (System.currentTimeMillis() - startTime < timeout) {
            String currentResultJson = redisTemplate.opsForValue().get(cacheKey);
            
            if (currentResultJson != null) {
                ChatResultMessage result = objectMapper.readValue(currentResultJson, ChatResultMessage.class);
                
                if (result.getStatus() == ChatResultMessage.ResultStatus.PROCESSING) {
                    // 发送处理中状态
                    sendSseEvent(emitter, "processing", Map.of(
                        "status", "processing",
                        "message", "AI正在处理您的请求..."
                    ));
                } else {
                    // 发送进度更新
                    if (result.getIntent() != null) {
                        sendSseEvent(emitter, "progress", Map.of(
                            "status", "progress",
                            "intent", result.getIntent()
                        ));
                    }
                    
                    // 发送新增内容
                    if (result.getResult() != null && !result.getResult().isEmpty()) {
                        String streamContent = getStreamContent(requestId);
                        
                        if (streamContent != null && streamContent.length() > lastContentLength) {
                            String newContent = streamContent.substring(lastContentLength);
                            if (!newContent.isEmpty()) {
                                sendSseEvent(emitter, "chunk", Map.of(
                                    "content", newContent,
                                    "status", "streaming",
                                    "fullContent": streamContent,
                                    "progress": Math.min(streamContent.length(), 100)
                                ));
                                lastContentLength = streamContent.length();
                            }
                        }
                    }
                    
                    // 处理完成或失败
                    if (result.getStatus() == ChatResultMessage.ResultStatus.SUCCESS ||
                        result.getStatus() == ChatResultMessage.ResultStatus.FAILED) {
                        sendSseEvent(emitter, "result", Map.of(
                            "requestId": result.getRequestId(),
                            "memoryId": result.getMemoryId(),
                            "status": result.getStatus().name(),
                            "result": result.getResult(),
                            "processingTimeMs": result.getProcessingTimeMs(),
                            "error": result.getErrorMessage()
                        ));
                        sendSseEvent(emitter, "complete", Map.of("event", "complete"));
                        
                        emitter.complete();
                        sseConnections.remove(requestId);
                        return emitter;
                    }
                }
            }
            
            Thread.sleep(checkInterval);
        }
        
        // 超时处理
        log.warn("SSE超时, requestId: {}", requestId);
        sendSseEvent(emitter, "timeout", Map.of(
            "status", "timeout",
            "message": "处理超时"
        ));
        emitter.complete();
        sseConnections.remove(requestId);
        
    } catch (Exception e) {
        log.error("SSE流异常, requestId: {}", requestId, e);
        sendSseEvent(emitter, "error", Map.of(
            "status", "error",
            "message": e.getMessage()
        ));
        emitter.completeWithError(e);
        sseConnections.remove(requestId);
    }
    
    return emitter;
}
```

```javascript
function connectSSE(streamUrl, waitingId, userMessage) {
    closeEventSource();
    
    accumulatedContent = '';
    isStreaming = true;
    
    eventSource = new EventSource(streamUrl);
    
    // 创建AI消息显示区域
    const aiMessageDiv = document.createElement('div');
    aiMessageDiv.className = 'message ai';
    const bubble = document.createElement('div');
    bubble.className = 'bubble';
    bubble.textContent = '';
    aiMessageDiv.appendChild(bubble);
    
    // 移除等待指示器
    removeTypingIndicator(waitingId);
    messagesArea.appendChild(aiMessageDiv);
    
    let lastChunkTime = Date.now();
    let chunkBuffer = '';
    const MIN_CHUNK_DELAY = 20;
    
    function processChunk(content) {
        if (!content) return;
        
        chunkBuffer += content;
        const now = Date.now();
        
        // 批量处理内容块，优化渲染性能
        if (chunkBuffer.length >= 10 || (now - lastChunkTime >= MIN_CHUNK_DELAY && chunkBuffer.length > 0)) {
            accumulatedContent += chunkBuffer;
            bubble.textContent = accumulatedContent;
            
            messagesArea.scrollTop = messagesArea.scrollHeight;
            
            chunkBuffer = '';
            lastChunkTime = now;
        }
    }
    
    // 监听连接事件
    eventSource.addEventListener('connected', (e) => {
        console.log('SSE连接已建立');
        updateConnectionStatus('connected', '已连接');
    });
    
    // 监听处理中事件
    eventSource.addEventListener('processing', (e) => {
        updateConnectionStatus('connecting', 'AI正在思考...');
    });
    
    // 监听内容块事件
    eventSource.addEventListener('chunk', (e) => {
        try {
            const data = JSON.parse(e.data);
            if (data.content) {
                processChunk(data.content);
            }
            
            if (data.status === 'streaming') {
                updateConnectionStatus('connected', '正在生成...');
            }
            
            if (data.progress !== undefined) {
                // 更新进度显示
            }
        } catch (error) {
            console.error('解析内容块失败:', error);
        }
    });
    
    // 监听进度事件
    eventSource.addEventListener('progress', (e) => {
        try {
            const data = JSON.parse(e.data);
            if (data.intent) {
                updateConnectionStatus('connected', '识别意图: ' + data.intent);
            }
        } catch (error) {
            console.error('解析进度失败:', error);
        }
    });
    
    // 监听结果事件
    eventSource.addEventListener('result', (e) => {
        try {
            const result = JSON.parse(e.data);
            
            // 处理剩余的缓冲区内容
            if (chunkBuffer.length > 0) {
                accumulatedContent += chunkBuffer;
                bubble.textContent = accumulatedContent;
                chunkBuffer = '';
            }
            
            isStreaming = false;
            
            if (result.status === 'SUCCESS' || result.status === 'success') {
                // 使用marked渲染Markdown
                bubble.innerHTML = marked.parse(accumulatedContent);
                aiMessageDiv.dataset.content = accumulatedContent;
                
                // 显示处理耗时
                const processingTimeDiv = document.createElement('div');
                processingTimeDiv.style.cssText = 'font-size: 0.75rem; color: #999; margin-top: 4px;';
                processingTimeDiv.textContent = '处理耗时: ' + (result.processingTimeMs || 0) + 'ms';
                aiMessageDiv.appendChild(processingTimeDiv);
                
                updateConnectionStatus('connected', '已完成');
                
                // 保存到历史记录
                if (currentMemoryId) {
                    conversationHistory.push({ 
                        role: 'ai', 
                        content: accumulatedContent, 
                        memoryId: currentMemoryId 
                    });
                    saveToHistory(currentMemoryId, conversationHistory);
                }
            } else {
                showError('处理失败: ' + (result.error || '未知错误'));
            }
            
            resetState();
            
        } catch (error) {
            console.error('解析结果失败:', error);
            isStreaming = false;
            showError('解析结果失败');
            resetState();
        }
    });
    
    // 监听完成事件
    eventSource.addEventListener('complete', (e) => {
        console.log('SSE流完成');
        closeEventSource();
        isStreaming = false;
    });
    
    // 监听错误事件
    eventSource.addEventListener('error', (e) => {
        console.error('SSE错误事件:', e);
        isStreaming = false;
        
        if (e.data) {
            try {
                const data = JSON.parse(e.data);
                showError(data.message || '连接错误');
            } catch (parseError) {
                showError('连接错误，请检查网络后重试');
            }
        } else {
            showError('连接错误，请检查网络后重试');
        }
        closeEventSource();
        resetState();
    });
    
    // 监听超时事件
    eventSource.addEventListener('timeout', (e) => {
        console.warn('SSE超时');
        isStreaming = false;
        showError('处理超时，请稍后重试');
        closeEventSource();
        resetState();

        closeEventSource();
        resetState();
    };
}

function resetState() {
    isProcessing = false;
    sendBtn.disabled = false;
    messageInput.disabled = false;
```

位置: `McpSseController.java`

```java
@RestController
@Tag(name = "MCP SSE服务")
@RequestMapping("/mcp")
public class McpSseController {
    
    @GetMapping(value = "/sse", produces = MediaType.TEXT_EVENT_STREAM_VALUE)
    @Operation(summary = "建立SSE连接")
    public SseEmitter connectSse(HttpServletRequest request, @RequestParam(required = false) String sessionId) {
        // 获取sessionId
        String headerSessionId = request.getHeader("X-Session-ID");
        
        if (sessionId == null || sessionId.isEmpty()) {
            sessionId = headerSessionId;
        }
        
        if (sessionId == null || sessionId.isEmpty()) {
            sessionId = UUID.randomUUID().toString();
        }
        
        logger.info("建立SSE连接: sessionId={}, clientIp={}", sessionId, request.getRemoteAddr());
        
        // 创建SSE发射器
        SseEmitter emitter = mcpSseService.createEmitter(sessionId);
        
        return emitter;
    }
    
    @PostMapping("/messages")
    @Operation(summary = "发送MCP消息")
    public Mono<Void> sendMessage(
            @RequestHeader(value = "X-Session-ID", required = false) String sessionId,
            @RequestBody McpMessage message,
            HttpServletRequest request) {
        
        String finalSessionId = (sessionId != null && !sessionId.isEmpty()) ? sessionId : UUID.randomUUID().toString();
        
        logger.info("接收MCP消息: sessionId={}, method={}", finalSessionId, message.getMethod());
        
        // 处理消息并通过SSE推送响应
        return mcpSseService.handleMessage(finalSessionId, message)
            .doOnError(error -> logger.error("处理MCP消息失败: sessionId={}, error={}", 
                finalSessionId, error.getMessage(), error));
    }
}
```

```java
private void cacheResult(String requestId, ChatResultMessage result) {

// 更新流式内容
private void updateStreamContent(String requestId, String content) {
    String cacheKey = STREAM_CACHE_PREFIX + requestId;
    try {
        String existingContent = redisTemplate.opsForValue().get(cacheKey);
        String newContent = (existingContent != null ? existingContent : "") + content;
        redisTemplate.opsForValue().set(cacheKey, newContent, RESULT_TTL);
```

```java
public class ResultStatusChecker {
    
    public SessionState checkStatus(ChatResultMessage result) {
        if (result == null) {
            return SessionState.NEW;
        }
        
        return switch (result.getStatus()) {
            case PROCESSING -> SessionState.PROCESSING;
            case SUCCESS -> SessionState.COMPLETED;
            case FAILED -> SessionState.ERROR;
        };
    }
    
    public boolean isTerminalState(SessionState state) {
        return state == SessionState.COMPLETED || 
               state == SessionState.ERROR ||
               state == SessionState.TIMEOUT;
    }
```

```java
// SSE异常处理策略
public class SseErrorHandler {
    
    private final SseEmitter emitter;
    private final String requestId;
    private int retryCount = 0;
    private final int maxRetries = 3;
    
    public void handleError(Throwable error) {
        if (error instanceof SseEmitter.SseEventException) {
            handleSseEventException((SseEmitter.SseEventException) error);
        } else if (error instanceof TimeoutException) {
            handleTimeout();
        } else if (error instanceof IOException) {
            handleIOException((IOException) error);
        } else {
            handleGenericError(error);
        }
    }
    
    private void handleTimeout() {
        log.warn("SSE连接超时, requestId: {}", requestId);
        
        try {
            sendErrorEvent("TIMEOUT", "处理超时，请稍后重试");
            emitter.complete();
        } catch (IOException e) {
            log.error("发送超时事件失败", e);
            emitter.completeWithError(e);
        }
    }
    
    private void handleIOException(IOException e) {
        log.error("SSE IO异常, requestId: {}, message: {}", requestId, e.getMessage());
        
        // 判断是否为客户端断开连接
        if (isClientDisconnected(e)) {
            log.info("客户端主动断开连接, requestId: {}", requestId);
            emitter.complete();
        } else {
            if (retryCount < maxRetries) {
                retryCount++;
                log.info("尝试重连, requestId: {}, 重试次数: {}", requestId, retryCount);
                attemptReconnect();
            } else {
                sendErrorEvent("CONNECTION_LOST", "连接已断开");
                emitter.completeWithError(e);
            }
        }
    }
    
    private void sendErrorEvent(String code, String message) throws IOException {
        Map<String, Object> errorData = new HashMap<>();
        errorData.put("status", "error");
        errorData.put("errorCode", code);
        errorData.put("message", message);
        errorData.put("retryEnabled", retryCount < maxRetries);
        errorData.put("retryAfter", 1000 * (retryCount + 1));
        
        String jsonData = objectMapper.writeValueAsString(errorData);
        emitter.send(SseEmitter.event().name("error").data(jsonData));
    }
    
    private boolean isClientDisconnected(IOException e) {
        String message = e.getMessage();
        return message != null && (
            message.contains("Broken pipe") ||
            message.contains("Connection reset") ||
            message.contains("Client closed connection")
        );
    }
}
```

```javascript
class ErrorHandler {
    constructor() {
        this.errorTypes = {
            NETWORK_ERROR: { retryable: true, message: '网络连接失败' },
            TIMEOUT_ERROR: { retryable: true, message: '请求超时' },
            SERVER_ERROR: { retryable: true, message: '服务器错误' },
            PARSE_ERROR: { retryable: false, message: '数据解析错误' },
            PERMISSION_ERROR: { retryable: false, message: '权限不足' }
        };
    }
    
    handle(error, context) {
        const errorInfo = this.categorizeError(error);
        
        // 记录错误日志
        this.logError(error, context, errorInfo);
        
        // 更新UI显示
        this.updateUI(errorInfo);
        
        // 决定是否重试
        if (errorInfo.retryable && context.retryEnabled) {
            return this.scheduleRetry(context);
        }
        
        return Promise.reject(error);
    }
    
    categorizeError(error) {
        if (error.name === 'TypeError' && error.message.includes('fetch')) {
            return this.errorTypes.NETWORK_ERROR;
        }
        
        if (error.name === 'AbortError') {
            return this.errorTypes.TIMEOUT_ERROR;
        }
        
        if (error.status >= 500) {
            return this.errorTypes.SERVER_ERROR;
        }
        
        if (error.status === 400) {
            return this.errorTypes.PARSE_ERROR;
        }
        
        return {
            retryable: false,
            message: error.message || '未知错误'
        };
    }
    
    updateUI(errorInfo) {
        const errorContainer = document.getElementById('errorContainer');
        errorContainer.innerHTML = `
            <div class="error-message show">
                <span>${errorInfo.message}</span>
                ${errorInfo.retryable ? 
                    `<button onclick="retryLastMessage()">重试</button>` : 
                    ''
                }
            </div>
        `;
        
        // 5秒后自动隐藏
        setTimeout(() => {
            errorContainer.innerHTML = '';
        }, 5000);
    }
    
    scheduleRetry(context) {
```

```javascript
class EventBus {
    constructor() {
        this.listeners = new Map();
    }
    
    on(event, callback, priority = 0) {
        if (!this.listeners.has(event)) {
            this.listeners.set(event, []);
        }
        
        this.listeners.get(event).push({
            callback,
            priority
        });
        
        // 按优先级排序
        this.listeners.get(event).sort((a, b) => b.priority - a.priority);
    }
    
    emit(event, data) {
        if (!this.listeners.has(event)) return;
        
        this.listeners.get(event).forEach(listener => {
            try {
                listener.callback(data);
            } catch (error) {
                console.error(`事件处理器错误: ${event}`, error);
            }
        });
    }
    
    off(event, callback) {
        if (!this.listeners.has(event)) return;
        
        const filters = this.listeners.get(event).filter(
            listener => listener.callback !== callback
        );
        
        this.listeners.set(event, filters);
    }
}
```

```java
// 连接池实现
public class SseEmitterPool {
    
    private final ConcurrentHashMap<String, PooledEmitter> pool;
    private final ScheduledExecutorService cleanupExecutor;
    private final int maxSize;
    private final long timeout;
    
    public SseEmitterPool(int maxSize, long timeout, long cleanupInterval) {
        this.maxSize = maxSize;
        this.timeout = timeout;
        this.pool = new ConcurrentHashMap<>();
        this.cleanupExecutor = Executors.newSingleThreadScheduledExecutor();
        
        // 定期清理过期连接
        this.cleanupExecutor.scheduleAtFixedRate(
            this::cleanupExpiredConnections,
            cleanupInterval,
            cleanupInterval,
            TimeUnit.MILLISECONDS
        );
    }
    
    public SseEmitter add(String key, SseEmitter emitter) {
        if (pool.size() >= maxSize) {
            // 移除最早的连接
            removeOldestConnection();
        }
        
        PooledEmitter pooled = new PooledEmitter(key, emitter, System.currentTimeMillis());
        pool.put(key, pooled);
        
        // 设置超时回调
        emitter.onTimeout(() -> remove(key));
        emitter.onCompletion(() -> remove(key));
        emitter.onError(e -> remove(key));
        
        return emitter;
    }
    
    private void cleanupExpiredConnections() {
        long now = System.currentTimeMillis();
        pool.entrySet().removeIf(entry -> {
            PooledEmitter emitter = entry.getValue();
            return now - emitter.getCreatedAt() > timeout;
        });
    }
    
    private void removeOldestConnection() {
        pool.entrySet().stream()
            .min(Comparator.comparingLong(e -> e.getValue().getCreatedAt()))
            .ifPresent(entry -> {
                entry.getValue().getEmitter().complete();
                remove(entry.getKey());
            });
    }
}
```

```javascript
class RequestBatcher {
    constructor(maxBatchSize = 10, maxWaitTime = 100) {
        this.queue = [];
        this.maxBatchSize = maxBatchSize;
        this.maxWaitTime = maxWaitTime;
        this.processing = false;
    }
    
    async add(request) {
        return new Promise((resolve, reject) => {
            this.queue.push({ request, resolve, reject });
            
            if (!this.processing) {
                this.processBatch();
            }
        });
    }
    
    async processBatch() {
        this.processing = true;
        
        // 等待更多请求或达到最大批次
        await new Promise(resolve => setTimeout(resolve, this.maxWaitTime));
        
        const batch = this.queue.splice(0, this.maxBatchSize);
        
        if (batch.length > 0) {
            try {
                const results = await this.sendBatch(batch.map(b => b.request));
                batch.forEach((item, index) => item.resolve(results[index]));
            } catch (error) {
                batch.forEach(item => item.reject(error));
            }
        }
        
        if (this.queue.length > 0) {
            this.processBatch();
        } else {
            this.processing = false;
        }
    }
    
    async sendBatch(requests) {
        // 实际的批量请求逻辑
        return Promise.all(requests.map(r => fetch(r.url, r.options)));
    }
```
